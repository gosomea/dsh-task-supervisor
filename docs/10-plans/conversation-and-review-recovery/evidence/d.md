# D：统一对话入口与故障 UI

历史列表移除独立目标输入框，改为“讨论新任务”。无任务也能打开同一持久对话，并默认进入对话页。草案显示标题、版本、完整要求及未决项；创建按钮绑定当时展示的草案版本、任务身份和修订号。请求被拒绝时保留草案及错误信息，不能静默丢失输入。

对话提供始终可见的“讨论／直接建任务”选项，复用 DSH 原生输入框。模式写入原生对话日志，直接创建只适用于选择模式之后发送的用户消息，不能事后授权旧消息。主 Agent 输出保持原样，主会话简略 DAG 与参与者展示保留。

故障详情明确表明没有有效审查决定，展示错误类型、尝试、原截止点、错误事件和原审查 Session。查看原审查日志复用原生会话展示，专用只读插槽不提供输入框；咨询对话仍有自己的原生输入框。有限自动恢复耗尽后才提供手动重试；重试不自动恢复执行。

使用 DSH 原生 Button、Disclosure 和主题 tokens。新增模式授权与陈旧草案/重复点击测试；双端类型和构建作为源码门禁。浏览器布局、正常操作及真实模型行为待 F 联合验证。
