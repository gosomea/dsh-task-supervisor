# 0.1.1 Standard DSH installation support

## Release scope

This release removes private Host event and reader-extension prerequisites, using public DSH persistent Inbox events and native Agent presets. Changes stay in Supervisor and evaluation readers; DSH main loop, Host, Client and native sandbox are unchanged. Source commit: `4cc5b47246f9ba158ae01c42da914756812ae9e9`.

Published to the [official npm registry](https://www.npmjs.com/package/dsh-task-supervisor/v/0.1.1), with `latest` at `0.1.1`. The public tarball matches the validated package byte for byte; digests and installation receipt are in the [release check record](0.1.1-checks.json).

## Install and use

```sh
dsh plugin --profile web add dsh-task-supervisor@0.1.1
dsh web
```

Run `/task new <objective>` before the first model turn in a blank Session, or select Supervisor mode first. Initial execution requires manual approval by default. A started ordinary Session cannot change its native preset; one Supervisor Session can retain history across successive tasks. Closing Supervisor keeps the preset; use a new ordinary Session for native Goal/Plan. See [standard installation and validation](../native-install.md).

## Validation results

Kernel source: 347 passed, 13 skipped. Strict Host/Client typechecks, build and package inspection passed. Evaluation readers passed 159 DeepSWE tests and 14 review-summary tests.

Official `@deepseek-ai/dsh@0.2.0-rc.2` loaded the plugin in isolation and completed a Chinese read-only task with CodeBuddy `deepseek-v4.1-flash`, one approval, node review and completion review. Removing the plugin caused native preset admission to reject restore; reinstalling restored the paused task and history. After publication, the native installation command installed npm version 0.1.1 and confirmed the same restore result.

## Remaining boundaries

Log review remains the default; independent artifact checks need storage and necessary execution capability configuration. This real task proves neither independent product execution nor long-horizon benchmark performance. Browser rendering and button interaction were not accepted in this run. Private 0.1.0 extension logs still use their original Host; start a fresh Session for this release. Automatic check-directory recovery remains unresolved. Full evidence and capability boundaries are in the [machine check record](../native-install-checks.json).
