# 0.1.5：审查者初始化与故障恢复

本补丁以已发布的 0.1.4 源码为基线。包与隔离宿主验收和 npm 发布分别记录于[验证记录](../../eval/team-compat-20261015/validation.zh.md)。

## 变更

每类审查都在 Agent 发布前的 setup 阶段登记持久的 Supervisor 一次性子 Agent 身份。创建事件观察者先看到完整身份，再安装作用域能力。Agent Teams 不向这些审查者安装 Team 工具与身份提示词；普通 Team Lead 保留其能力。恢复审查者时沿用已有描述记录，并在发布前拒绝不匹配的提供方或模式。

审查器在宿主简化持久错误表示前捕获作用域内的原生异常。只有实际 LLM 异常，或原始通知不可用时已识别的原生提供方异常，才归为模型请求故障。本地及未知异常使用现有内部故障类别，并在消息中保留可用的诊断码。不改变持久化 schema，也不改写历史记录。

控制器与 Web 展示共用自动重试准入规则。界面明确计数为自动故障重试，并解释已记录的策略排除、未启用、仅手动恢复和次数用尽。手动恢复仍须符合当前 Task 与控制器许可。未知异常不会因此获得自动重试资格。

## 升级行为

自动及手动恢复保留作业原截止时间。已过期作业不能通过重试获得下一次模型尝试或执行批准；原截止内的重启恢复保留同一作业、证据截止点和审查者身份。此前已记录裁决沿用其既有应用规则。

先将验收后的压缩包安装到独立 profile 验证。发布后，通过标准 `dsh plugin --profile <profile> add` 命令安装 `dsh-task-supervisor@0.1.5`。加载新包需要受控的宿主重载或重启；仅安装不会更新正在运行的审查者。调整日常宿主前须保留记录并核对当前活动。

## 范围

本补丁修改外部 Supervisor 插件，不修改 Agent Teams 或 DSH 主循环，也不包含尚未发布的持续执行候选。历史开发回归得分与封口结果保留原身份。
