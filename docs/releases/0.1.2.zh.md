# 0.1.2 原生 DSH 模式中的任务

[English](0.1.2.md) | 中文

2026-10-08 已发布到[官方 npm 仓库](https://www.npmjs.com/package/dsh-task-supervisor/v/0.1.2)，`latest` 为 `0.1.2`。公开压缩包与已验证产物逐字节一致。

## 变更

无需选择独立 Supervisor 模式即可建立督导任务。使用 `/task <目标>`、单独 `/task` 后输入目标，或让主 Agent 创建任务。原生 Goal/Plan 工具仍可组织工作；Supervisor 负责 Task 的批准、续行和验收。

侧栏使用精简的对话页头和内联任务草案。主 Session 保留原生回答，显示 DAG 进度、参与 Agent 和审查通知。审查详情显示实际活动、耗时、截止时间及下一步；活动次数不代表完成百分比。

正式计划、节点和完成提交持久保存审查作业并快速返回。控制器交接后运行审查，不占用发起 PTC 调用的等待预算。暂停、关闭、版本失效、审查截止和重启保留各自取消与恢复语义。已完成任务支持只读诊断、明确创建下一任务及需确认影响范围的修复提案。

## 安装与升级

```sh
dsh plugin --profile web add dsh-task-supervisor@0.1.2
dsh web
```

重启 Host 加载升级前，先让在途工作结束或暂停。新任务使用原生模式；仅恢复 0.1.1 专用 preset 的旧 Session 时设置 `legacyPresets: true`。不改写 0.1.0 私有扩展日志，这些记录仍需原 Host。

## 验证与边界

[发布检查记录](0.1.2-checks.json)保存构建、Host/Client 严格类型、内核回归、包内容及安装检查。本源码已有的隔离真实模型和界面证据见[原生任务](../native-task.zh.md)、[控制器审查交接](../review-queue.zh.md)及[审查进度](../review-progress.zh.md)；打包检查不是新一轮模型或浏览器测试。

默认仍为日志审查。独立产物读取及隔离执行需要显式配置，独立浏览器观察尚不可用。审查可能遗漏缺陷。本版不证明优于 Goal、Plan 或 Agent Team；完整流程与限制见 [README](../../README.zh.md)。
