# 0.1.1 普通 DSH 安装支持

## 发布范围

本版本移除私有 Host 事件和读取器扩展前提，改用公开 DSH 的持久 Inbox 与原生 Agent preset。变更限于 Supervisor 插件及评测读取适配，没有修改 DSH 主循环、Host、Client 或原生沙箱。源码提交为 `4cc5b47246f9ba158ae01c42da914756812ae9e9`。

已发布到 [npm 官方仓库](https://www.npmjs.com/package/dsh-task-supervisor/v/0.1.1)，`latest` 为 `0.1.1`。公开 tarball 与本轮验收包逐字节一致；摘要与安装回执见[发布检查记录](0.1.1-checks.json)。

## 安装与使用

```sh
dsh plugin --profile web add dsh-task-supervisor@0.1.1
dsh web
```

在新建空白 Session 的第一轮模型对话前运行 `/task new <目标>`，或先选择 Supervisor 模式。初始计划默认需用户批准。已开始的普通 Session 不能更换原生模式；同一 Supervisor Session 可以创建后续任务并保留历史。关闭督导不改变 preset，需要原生 Goal／Plan 时新建普通 Session。详细说明见[普通安装与验收](../native-install.zh.md)。

## 验证结果

源码内核 347 项通过、13 项跳过；Host／Client 严格类型检查、构建和包检查通过。评测读取器 159 项 DeepSWE 测试与 14 项审查汇总测试通过。

官方 `@deepseek-ai/dsh@0.2.0-rc.2` 在隔离环境加载插件，以 CodeBuddy `deepseek-v4.1-flash` 跑通一次批准、节点审查、完成审查和中文只读任务。卸载插件时原生 preset 拒绝恢复；重新安装后恢复暂停任务及历史。发布后又通过原生安装命令从 npm 安装 0.1.1，并确认相同恢复结果。

## 保留的边界

默认仍为日志审查；独立产物检查需要另行配置存储和所需运行能力。此次真实任务不证明独立运行过产物，也不构成长程基准。浏览器渲染与按钮操作本轮未验收。0.1.0 的私有扩展日志仍使用原 Host，请为本版本新建 Session；检查目录自动恢复仍待修复。完整证据及能力边界见[机器检查记录](../native-install-checks.json)。
