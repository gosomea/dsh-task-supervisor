# 0.1.7：可操作的要求来源错误

用户消息来源使用 `source.reference=seq:<消息编号>`，例如 `seq:594`。用户原话应放在 `requirement`。工具 schema 在模型提交裁决前说明此格式。

引用格式错误返回 `INVALID_REQUIREMENT_SOURCE_REFERENCE`，指出字段位置与修改方式；引用格式有效但原文未读时返回 `UNREAD_REQUIREMENT_SOURCE`，指出应读取的确切 seq。修正引用不要求重读已经交付的原文。证据准入与验收规则继续执行。

日常 0.1.6 审查暴露了反复填入用户原话、错误提示却引导重读的问题。保留其原作业和截止时间。修正通过独立的 0.1.7 包交付，不修改活动审查者，也不追加救场提示词。
