# 0.1.0 development preview

## Version scope

This version packages the accepted implementation at `1dfb95d` as a built DSH plugin. It includes task drafts, DAGs and node rework, persistent consultation, planning supervision, explicit execution preauthorization, requirement-driven independent check plans, evidence binding and two-phase review.

Main Agent answers retain native output; an independent Session identity does not establish independent verification. Review records separate main reports, main execution logs and evidence the reviewer actually read or ran. Original user requirements remain authoritative.

## Runtime prerequisites and limits

- An isolated DSH Host with durable `extension/record` and reader admission is required; standard DSH does not include that extension yet. npm installation does not supply it.
- `reviewVerification: log` is the default; independent checks require explicit storage and any necessary runner. Static requirements may need reading only, while behavioral requirements need an appropriate execution capability.
- This version supports artifact reading and isolated command execution, without independent browser or visual inspection.
- A command that changes the captured artifact tree cannot supply acceptance evidence. The gateway rejects later commands, which may pause review with an internal fault. Automatic directory recovery still needs repair and real-container validation and is excluded from this release.
- A host restart waits for manual resume. Repair after completion presents its impact and returns to the original task and DAG only after the user confirms each proposal.
