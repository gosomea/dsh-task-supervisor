# 0.1.0 开发预览

## 版本范围

本版本以 `1dfb95d` 的已验收实现为基线，发布预构建的 DSH 插件。包含任务草案、DAG 与节点返工、持久督导对话、规划监督、明确执行预授权，以及要求驱动的独立检查方案、证据绑定和两阶段审查。

主 Agent 回答保持原生输出；独立 Session 身份本身不代表已独立验证。审查记录区分主汇报、主执行日志和审查者实际读取或运行所得证据，原始用户要求仍是验收依据。

## 运行前提与限制

- 需要支持持久 `extension/record` 及读取器准入的隔离 DSH Host；标准 DSH 尚不包含该扩展。npm 安装不会补齐它。
- 默认 `reviewVerification: log`；独立检查须显式配置存储与所需运行器。静态要求可只读取，行为要求须有对应执行能力。
- 本版本提供产物读取和隔离命令运行，不提供独立浏览器或视觉检查。
- 命令修改捕获的产物树后，该证据不能用于验收；后续命令被检查网关拒绝，可能导致审查故障暂停。检查目录自动恢复仍待修复与真实容器验收，未纳入本次发布。
- 宿主重启等待手动恢复。完成后的修复展示影响范围，每次由用户确认后回到原任务与 DAG。

已有通用正反例、静态产物真实模型与内核检查记录见[通用审查验收](../../eval/independent-verification/generic-quality-20260930/README.zh.md)。发布构建与包检查单独记录，不能替代行为验收。
