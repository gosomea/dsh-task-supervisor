# 0.1.5: reviewer initialization and failure recovery

This patch is based on the published 0.1.4 source. Package and isolated-Host acceptance are recorded separately from npm publication in [the validation record](../../eval/team-compat-20261015/validation.md).

## Changes

Every review kind establishes its durable one-shot Supervisor identity during unpublished Agent setup. Creation observers see that identity before installing scoped capabilities. Agent Teams excludes these reviewers from Team tools and identity prompts; ordinary Team Leads keep their capabilities. Resuming a reviewer preserves its existing descriptor and rejects an incompatible provider or mode before publication.

The reviewer records scoped native errors before the Host reduces their durable representation. Only an actual LLM failure, or a recognized native provider failure when the original notification is unavailable, is classified as a model request fault. Local and unknown failures use the existing internal-fault category and retain an available diagnostic code in their message. No persistence schema or historical record is rewritten.

The controller and Web presentation share automatic-retry eligibility. The interface labels the counter as automatic fault retries and explains recorded policy exclusions, disabled retries, manual-only recovery and exhausted attempts. Manual recovery still requires the current Task and controller permission. Unknown failures do not become automatically retryable.

## Upgrade behavior

Automatic and manual recovery retain the original job deadline. An expired job cannot obtain another model attempt or execution approval through retry; restart recovery within the original deadline keeps the same job, evidence cutoff and reviewer identity. Previously recorded decisions retain their existing application rules.

Install the accepted tarball into a separate profile for validation. After publication, install `dsh-task-supervisor@0.1.5` through the normal `dsh plugin --profile <profile> add` command. Loading a new package requires a controlled Host reload or restart; installing alone does not update an already running reviewer. Preserve its records and check current activity before changing the daily Host.

## Scope

The patch changes the external Supervisor plugin. It does not modify Agent Teams or the DSH loop, and it does not include the unreleased continuous-execution candidate. Historical development-regression scores and sealed results keep their original identities.
