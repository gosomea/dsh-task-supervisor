# 0.1.6：恢复过期审查与查询被阻塞的 Task

## 恢复

审查已过期的暂停 Task 提供**重新审查**（`/task restart-review`）。用户明确操作后建立新作业、新审查 Session 与新截止时间。原失败作业、证据截止点、故障历史与截止时间保持原样。新审查绑定同一要求、计划、节点尝试和提交证据；绑定变化或控制版本过期时拒绝操作。

重新审查不授予执行权限。计划通过后等待用户批准，已批准的工作等待手动恢复执行。自动恢复与 `/task retry-review` 保留原作业截止时间。

## 诊断

暂停、审查中及关闭的 Task 直接提供 `task_status`，包括 PTC 预设。任意程序和执行工具继续被阻止。状态与门禁错误说明阶段、故障及可用用户操作。离开阻塞状态后恢复预设的工具呈现。

## 宿主兼容

审查者在发布前写入公开的带版本一次性身份记录。由控制器管理的审查者不使用当前宿主仅接受可续行子 Agent 的描述构建器。类型声明显式导入持久化服务定义，源码夹具通过命名空间挂载当前 JSONL 插件。

## 交付

通过 `dsh plugin --profile web add /absolute/path/to/dsh-task-supervisor-0.1.6.tgz` 安装已验收的本地包 `dsh-task-supervisor-0.1.6.tgz`，检查活动后重载宿主。本地压缩包部署不代表 npm 已发布。历史回归评分与用户 Task 记录保留原身份。
