# dsh-task-supervisor: supervision, DAG progress and stage acceptance for long DSH tasks

I built **dsh-task-supervisor** to address a practical problem: while an Agent keeps working, does its plan cover the requirements, where has execution reached, and what evidence supports its claim that the task is complete?

The main Agent continues to plan and execute in its native Session. Supervisor persists task state and starts a separate review Session at planning, stage and completion checkpoints. A controller then admits continuation, requests revision or waits for the user. Main Agent answers keep their native presentation; review feedback identifies its separate source.

The preview offers:

- **Plan coverage review**: compare a submitted plan with the original requirements before user approval; explicit preauthorization can admit execution after a passing review.
- **DAG and rework progress**: a compact main-conversation view and detailed sidebar show stages, participating Agents, review evidence and attempts. Rework retains its reason and affected descendants.
- **Supervisor consultation**: discuss objectives or ask about progress in the sidebar, and explicitly pause, resume or close supervision.
- **Repair after completion**: inspect the proposed impact and confirm a return to the original task and DAG, keeping earlier acceptance records.
- **Persistent tasks and history**: restore task records after restart, with execution waiting for manual resume; start another task in the same Session after completion.

**0.1.1 is published on npm as a development preview.** Installation was validated with Node 24 and official DSH `0.2.0-rc.2`. It installs into unmodified DSH without Host patches or a custom build. Keep your existing Web profile and model configuration:

```sh
dsh plugin --profile web add dsh-task-supervisor@0.1.1
dsh web
```

In a blank Session, enter `/task new <objective>` before the first model turn. To discuss an objective first, select Supervisor mode before the first message. After plan review passes, use `/task approve` or the sidebar button by default. A started ordinary Session requires a new supervised Session.

For a small trial, prepare `input.txt` with `8` and `12` on separate lines, then enter:

```text
/task new Read the integers in input.txt in the current workspace, calculate their sum and report it in English. Keep the file unchanged.
```

Default review reads the main Session log; **a separate Session alone does not establish independent artifact verification**. Enable independent verification and the required capabilities for direct artifact reading, recomputation or behavioral checks. Independent browser observation is unavailable, and long-horizon comparisons do not yet establish superiority over Goal or Plan. If a command modifies the captured artifact tree in this release, its evidence becomes invalid and subsequent checks are rejected; recovery remains under development.

Feedback from DSH users is welcome, particularly reproducible plan omissions, premature completion, unnecessary pauses, rework and recovery issues. Include DSH/plugin versions, reproduction steps and expected versus actual behavior. Remove credentials and authentication links from shared logs.
