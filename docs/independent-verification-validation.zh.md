## 步骤 2：快照与原生运行器

状态：快照与运行器基础代码已实现，通过宿主无关测试和 macOS 原生服务测试；尚待步骤 3 接入正式节点与完成审查。用户 59909 实例和冻结公开题 runner 没有更新。

快照包含实际工作树中的未提交、未跟踪文件；明确记录排除路径，默认仅排除 `.git`。超过文件数或字节数上限直接报错。复制前后的内容清单必须一致；捕获竞争最多重试两次。相对且位于捕获范围内的软链接可保留，绝对、外部、指向排除内容的链接和特殊文件拒绝。基线与检查副本不共享 inode。

运行器消费 DSH 原生 sandbox 与 subprocess 服务，使用结构化 argv、独立 HOME/TMP/缓存与清空的环境。严格验证策略只向检查目录授予写权限，限制读取到声明的工具链路径，禁止网络；运行器要求完整执行且明确返回 verificationEnforced。旧宿主或不支持读取与网络隔离的后端直接报基础设施故障，不无约束运行。macOS 使用 Seatbelt；Linux bubblewrap 代码路径尚待实际平台验证；Landlock 与 Windows ACL 明确不支持。

检查结果分别记录退出码、信号、超时、取消、输出是否完整，以及捕获源码是否被修改。原生受管进程范围必须收敛后才能返回；检查证据保存在命令不可写的作业目录。源码修改不能以修复后测试通过来批准原产物。
