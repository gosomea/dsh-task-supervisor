## 实际问题

## 修复

- 正式裁决应用后重置主 Agent 的观察窗口。空闲观察不能重复审查该截止点以前的轮次。实际继续规划后仍按原频率检查新活动，不关闭进展审查。
- 主会话和侧栏显示当前有效作业的待审 DAG，明确标注尚未批准。需修订时标注待修订；版本不匹配不展示旧提案。预览不更新已批准计划，不授予执行权限。
- 区分计划、规划进展、节点和整体验收。展示实测耗时、证据读取次数、工具失败次数、最近记录更新时间和作业截止时间，并说明下一步是返回规划、等待批准或继续实施。
- 活动来自当前审查 Session 的实际事件；没有完成百分比。成功读取次数不等于要求覆盖，也不代表独立产物检查。日志审查不再显示“零次独立检查”。
- 可打开只读实时审查记录；正在运行时每两秒刷新，关闭后释放计时器与请求。读取接口不启动模型、恢复审查或批准任务。

主 Agent 回答仍用原生显示。本次没有修改 DSH 主循环、沙箱、PTC 默认预算、批准策略或进展触发频率。
