# 完成后修复协议

已完成任务中的原目标缺陷通过修复提案回到原任务与 DAG。普通问询只读取状态；模型或用户提出修复时先展示影响范围，每次重开由用户点击确认。新增功能或不同目标仍使用新任务草案。

## 提案与确认

主 Agent 使用 `task_propose_repair`，督导对话使用 `supervisor_propose_repair`。两者提交任务 ID、精确状态版本、短标题、缺陷原因、直接受影响根节点与主 Session 证据序号。用户也可从当前或历史任务详情直接提出修复。提案保存来源与提出者 Session 身份，界面区分主 Agent、督导对话和用户手动提案；旧记录未保存身份时不补造。

提案保存为主 Session 的持久事件，控制器计算多个根节点及依赖后代的并集。共同下游只重置一次。提案不改变已完成状态，不唤醒实施，也不授予模型重开的工具权限。主会话概览显示“修复提案待确认”，点击后在侧栏查看范围；确认按钮使用 DSH 原生按钮。旧主 Agent 回答保持原样。

已提交提案等待决定时，当前主 Agent 的实施工具被拒绝。模型不能用 `task_approve`、`task_rework_node` 或恢复命令代替确认。诊断代码与 shell 的完整只读沙箱仍属于独立运行器步骤；提示词中的只读约束不能被描述为文件系统沙箱。

确认走 Connection 的原生认证 Fetch 路由，绑定提案 ID、目标任务 ID 和版本。控制器先等待主 Agent 空闲，再在原生 maintenance 窗口中核对执行名额、目标版本与工作区身份，保存确认收据，追加确定性的新任务状态，并持久保存续行消息。任何核对失败都不实施。另一个活跃任务占用名额时返回 `ACTIVE_TASK_CONFLICT`，不抢占、不自动排队。

同一提案的重复点击不产生第二次续行。新提案使旧的待确认提案失效。暂不修复保留原完成状态；历史提案不从摘要或旧用户消息重新获得授权。

## 工作区身份的边界

提案通过 DSH 原生文件系统读取绑定工作区，两次捕获目录元数据与文件字节摘要。未跟踪和未提交文件纳入，根目录 `.git` 元数据排除；提案之后内容或元数据改变，确认返回 `ARTIFACT_CHANGED`，需要更新提案。

默认完整捕获上限为 10000 个目录项与 256 MiB 文件内容，分别可配置 `repairMaxFiles`、`repairMaxBytes`。超限明确失败，不静默跳过文件。软链接与特殊文件目前拒绝，返回 `ARTIFACT_UNSUPPORTED`；后续快照步骤再定义外部依赖策略。没有原生文件系统或绑定目录时返回 `ARTIFACT_UNAVAILABLE`。

此身份仅证明确认对应展示提案时的工作区，**不是独立验收快照，也不能证明此前完成时的代码仍全部正确**。外部进程在核对结束后继续写入的竞争尚需下一步运行器策略解决。最终完成仍由既有审查决定，独立运行检查尚未在这一步新增。

## 验收轮次与历史

确认后任务 ID、目标、获批计划与 DAG 保留，`acceptanceCycle` 从默认第 1 轮递增。根节点及后代增加尝试号并重新审查；独立节点保留通过。整体完成结论清空，修复后必须再次申请最终完成审查。此前轮次的节点状态、完成审查、完成时间（旧日志可能缺失）、确认时间、原因与影响范围保存在 `repairHistory`，在详情中连续查看。

重开历史任务时恢复该任务的审查和返工记录，将原来当前的已结束任务放回历史。历史列表按任务 ID 去重，避免同一任务每次修复变成新的任务条目。

重启可恢复提案和轮次，不自动实施；已确认但尚未完成状态追加时，仍须用户重新点击才能继续。已重开的执行若重启，按既有 `/task resume` 手动恢复。关闭督导或版本变化会阻止旧提案；旧审查回调仍受任务版本与作业身份约束。

## 持久化契约

任务 `dsh-task-supervisor/state` schema 从 9 升为 **10**，读取 1–10；新增轮次、完成时间与历史字段均可选；提案来源保存在修复 namespace 中。旧记录不补造完成时间或确认收据。投影缓存版本从 10 升为 **11**，从原生日志重建当前任务、历史任务、审查与提案。

新增 `dsh-task-supervisor-repair` schema **1**，事件种类为 `proposal`、`confirm`、`decline`。确认记录包含 `source=web-confirmation` 与精确目标，投影只接受其对应的确定性完成到执行转换；直接追加没有匹配收据的重开状态会使投影拒绝执行。提案窗口最多保留 50 项，原始事件仍在 Session 日志中。

注册读取器遵循 Cordis effect。旧插件不支持 schema 10 或新修复 namespace 时，DSH 原生读取器准入会拒绝继续受控 Session，不能降级成无监督执行。客户端、冷日志读取、历史恢复与模型状态工具同步读取新字段。
