# 长程执行与配对评测协议

本批验证受督导 Task 能否持续执行、在预算内恢复，并产出通过独立验收的结果。实现从 `de75f7a` 开始，既有基准成绩保持原样。[English](protocol.md)。

## 执行与授权

插件负责规划、审查、有界恢复与续行。确定性 Python 监控器负责初始批准、明确授权的开发修订、沙盒寿命、收集、评分与封口。监控器不发送救场提示，也不恢复已暂停的 Task。

任务预算跨重规划、审查重试及重启持久保留。默认每 Task 最多六次截断续行、三次暂时审查故障重试，沿用连续两次无进展及单审查作业重试一次的限制。预算预留不改变审查绑定的任务 revision。用户暂停、关闭、重启及需要用户决策仍须人工恢复。所有动作服从原截止时间。

开发修订题允许一次初始批准和对冻结修订文本的一次授权。事件屏障在首次节点尝试通过后阻止下一节点调度。监控器交付修订，等待新计划覆盖裁决有效应用，再仅授权该要求版本一次。公开题保持固定目标，最多一次初始批准。

## 准入与冻结输入

使用明确提供的冻结安装包、固定 DSH／Node、镜像摘要及每运行私有 home。题目投递前实测原生读取、工作区写入、执行与越界拒绝。权限沙盒不可用属于基础设施准入失败，不能借此升权。

凭据和模型请求之前捕获 baseline；恢复后核对题目文件。通过任务私有 socket 和产物租约连接现有管理员检查网关，仅管理员服务拥有 Docker 控制。验证快照、独立检查、清理、官方空补丁／参考补丁评分、资源容量，以及主 Agent／审查者实际模型路由。配置转储或 HTTP 200 不足以证明准入。

监控器每 60 秒观察，时序敏感动作采用持久事件屏障。中断后连接原沙盒；60 分钟寿命剩余不足 15 分钟时续期，不延长任务截止。完成、截止、预算耗尽、用户决策、执行侧退出或沙盒消失后收集并封口。已启动位置不得重新投递，结果不得覆盖。

## 公开对照与报告

仅按元数据，从 DeepSWE v1.1 的 `0b9fabbb63b9104d678fe965e1632f2dd9eaa2ea` 提交选两道 Go、两道 TypeScript 题，使用 `protocol.json` 中的固定种子。排除曝光及已投递题。记录准入失败，仅能在模型投递前按固定候选顺序替换。四题、顺序、运行产物、配置及评分器全部冻结后进行对照。

每题 Goal、Plan、Supervisor-independent 各两次，共 24 个位置；串行运行，保持官方执行时限及主环境 CPU／内存。主模型路由与推理设置一致；审查者、网关及独立检查成本单列。仅将 Agent 已提交的二进制补丁交给外部官方评分器。

报告完整分母、官方 reward、可用的 F2P／P2P、控制器完成、截止、内部／基础设施／评分故障、全部 Session token、请求、审查／检查等待、恢复、重复读取、人工动作及逐题配对结果。严格成功须及时完成、reward 为 1，且没有基础设施或评分故障。未标注的误验收、误暂停及纠偏收益保持 null。四题不能证明优越性或通用长程性能。
