# DSH 长任务督导

**设计提案；目前没有可安装插件。** 本项目面向 DSH，目标是用一套受督导的任务生命周期替代原生 Goal 与 Plan 的用户工作流。主 Agent 在原会话中规划和执行；独立审查者检查已记录的工作，推动续行，并独立判断是否完成。

## 预期用法

插件依据任务选择较短的单轮路径或自主多轮续行，并可在执行中切换。首次进入自主多轮前，用户确认一次初始任务理解和计划。主 Agent 可依据新证据调整计划；督导从同一主会话日志读取用户指令，审查调整，并在仍有工作时开启下一轮。

主 Agent 可以申请完成；督导根据证据裁决是否成立。确认停滞时，插件暂停并请用户决策。宿主重启后恢复任务状态，但不静默恢复执行。

## 与 DSH 的关系

这是 DSH 源码树外的插件项目。目标配置档将替代原生 Goal 与 Plan 控制，不让两套控制器同时管理同一会话。实现将使用 DSH 插件注册、持久 session event、projection、agent 生命周期钩子与原生客户端扩展点。已有的 [Jev 验证原型](../dsh-jev-verifier/README.md) 提供经验与可选择移植的代码，不决定新项目架构。
